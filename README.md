# Body Forge 💪

A workout tracker web app built with HTML, CSS, and JavaScript — converted to a native Android APK using WebView.

## Features
- Circuit timers, rep counters, and rest timers
- Streak tracking across sessions
- 14-day workout history
- Mobile-first design, works fully offline

## Tech Stack
- Frontend: HTML, CSS, JavaScript (single file)
- Android: WebView wrapper (package: com.pms.bodyforge)
